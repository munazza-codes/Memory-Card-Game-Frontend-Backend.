# Memory Card Game

A simple and fun memory card game made by me.
Match all 10 pairs of colorful shapes and test your memory.

## How to choose

- Click on any card to reveal the shape.
- Click another card to find its matching pair.
- Match all 10 pairs to win the game.

## Features

- 10 memory pairs
- Random card shuffle
- Timer
- Moves counter
- Pairs counter
- Match animation
- Win screen
- Play Again button
- Frontend and backend connection
- Game results saved in backend
